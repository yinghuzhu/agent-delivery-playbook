# 研究记录约定

按复杂度使用，在已有文档中补齐即可。短任务可以只在回复中保留必要信息；长期研究建议用一个状态入口连接证据和专项报告，避免每轮生成互相冲突的“最终结论”。

## 状态入口

记录研究问题、当前模式、要支持的决定、完成标准、用户已确认口径、授权及暂停事项、证据范围、当前结论、未决项、下一步和停止/重开条件。

恢复研究时先核对这些信息，再判断哪些旧证据需要更新。完成的事实核验可以复用；来源、版本、时间或目标变化时只补查受影响部分。历史授权不自动适用于新任务。

## 证据记录

给证据稳定 ID，例如 E01。至少能回查：

- 来源主体、URL 或项目相对文件、原文定位；会话材料保留会话 ID、消息时间或记录位置。
- 采集时间与来源所描述的事件时间、数据基准或版本，二者不可混用。
- 实际查看或取得了什么，以及取得失败、缺失或未检查的部分。
- 支持的事实、适用对象和范围、限制及关联结论。
- 独立性：同源转载、相同作者/事件/数据集如何归组。

可下载材料有必要复现时保存原始响应、版本及哈希；搜索摘要优先回到原文核实。资料只能登录查看或不得留存时，记录访问方式和必要定位，不承诺他人可公开复现。敏感原文按权限保存，报告使用脱敏摘要，不复制凭证或无关个人信息。

## 结论与决定

给关键结论稳定 ID，例如 C01，关联支持证据、反证、适用范围及剩余未知。分别标记：

- **事实**：材料直接支持什么；“来源声称”与事实已获外部核实仍有区别。
- **推断**：基于哪些事实、通过什么理由得出；保留替代解释。
- **假设**：等待验证的判断，写出可支持或否定它的观测。
- **未知**：尚不能判断的内容及原因。

决定记录本轮的新证据、改变的结论、继续/切换/结束理由及下一步。业务裁决注明用户确认，不把 agent 建议标成已确认。旧结论被替代时保留关系与原因，不删除不利证据。

## 交接字段

需要委派或交接时按[研究子 agent 编排](agent-orchestration.md)提供任务单，并在本状态入口维护任务 ID、依赖、执行者/会话、模型、状态和最近证据。公共结论与台账由主 agent 统一维护，子任务返回进入待核验；不得预设接手者读过历史对话。

结束时记录实际执行者、时间、使用的资料版本以及未执行项。文档自查、历史桌面回放、独立行为测试、在线实测分别标记，不能互相替代。

## 可移植性

skill 内部资源按引用文件所在目录解析；研究产物按实际目标项目的文档根解析。正文、命令和链接不用开发机绝对路径、用户名或未声明的内部地址。来源地址若敏感，使用证据 ID 和受控配置定位，不将其写入公共模板。

不得要求用户安装某个固定浏览器、搜索服务或模型才能开展通用研究。按当前环境发现可用能力，工具缺失时说明影响并采用可行路径，不假称已经验证。
